# Contributing

Thanks for your interest in contributing to Fitness API.

## How to contribute
1. Fork the repository
2. Create a new branch for your change
3. Make your changes
4. Add or update tests when behavior changes
5. Run the automated checks through GitHub Actions
6. Open a pull request with a clear description of the change

## Contribution requirements
- Keep changes focused and small when possible
- Update documentation when behavior changes
- Add or update tests for new functionality or bug fixes
- Do not commit secrets, tokens, passwords, or private keys
- Follow the existing project structure and naming style

## Bug reports
Use GitHub Issues to report bugs.

## Feature requests
Use GitHub Issues and label the issue as an enhancement when appropriate.
